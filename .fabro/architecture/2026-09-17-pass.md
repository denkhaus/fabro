### Split the fabro-server server/tests.rs monolith into per-handler-domain test modules — filed fabro-90ae

`lib/apps/fabro-server/src/server/tests.rs` is 21,876 lines / 373 test functions with zero internal modules — the repo's top product-code churn (59 touches/30d). Concrete change: split into `server/tests/<domain>.rs` files mirroring `server/handler/` domains (sessions, runs, sandbox, lifecycle, pair, events, graph, system) with shared fixtures behind one cfg(test) support module; moves only, no test-content change. Expected effect: locality per handler, smaller review diffs, fewer collisions across parallel develop and merge-upstream lines, cheaper agent navigation. Cross-checked against open fabro-ab8e (fork-footprint extraction from the same file) — distinct; coordinate so fork tests land in fork-owned modules per ADR-0021. Dedupe searches ("monolith", "split") found no duplicate.

### Resolve crate-relative seed anchors in anchor_check.nu before flagging missing_file — filed fabro-7611

`.fabro/workflows/develop/scripts/anchor_check.nu` joins cited paths against repo root only, so crate-relative anchors (e.g. fabro-0863's `operations/create.rs:556-585` inside `lib/components/fabro-workflow/src/`) flag missing_file falsely. Concrete change: when the root-joined path is absent, retry against workspace member roots from Cargo.toml before emitting missing_file, and include the resolved base in the verdict row. Expected effect: false missing_file flags disappear as a class; planner laps stop re-deriving path bases by hand. Extends landed fabro-7daf; same ambiguity family as open fabro-1a35 (different mechanism) — cross-referenced. Dedupe searches ("anchor", "missing_file", "crate") found no duplicate.
