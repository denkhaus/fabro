## 1. Deepen the fabro-server test surface: split the monolith by handler domain — Strong

- **Files**: `lib/apps/fabro-server/src/server/tests.rs` — 21,876 lines, 373 test functions, zero internal modules (flat); `lib/apps/fabro-server/src/server/handler/` — 27 domain modules.
- **Problem**: the file is a shallow module of accidents. Its "interface" is the whole 21.9k-line body: no locality (understanding one handler's test contract requires the entire file), no leverage (every handler change touches the same file — 59 touches/30d, the top product-code churn in the repo), and two collision sources pay for it continuously: parallel develop lines, and upstream merges (fork additions live interleaved, the exact friction `fabro-ab8e` measures). Loop agents pay it per implementer/reviewer lap — grep works, but anchors, review diffs, and token cost all scale with the file. Hand-enforced conventions inside it (`fabro-dd29`) have no natural home.
- **Deletion test**: deleting the file and re-homing each domain's tests beside its handler **concentrates** test knowledge where the domain lives; test discovery (`cargo nextest`, the interface) is file-layout agnostic — nothing moves except complexity, into locality.
- **Solution**: split into per-domain test modules under `lib/apps/fabro-server/src/server/tests/` mirroring `handler/` domains (sessions, runs, sandbox, lifecycle, pair, events, graph, system, …) with shared fixtures in one `cfg(test)` support module. Moves only — no test-content change. Coordinate with open `fabro-ab8e` (fork-footprint extraction names this file): the split should land fork-owned tests in fork-owned modules per ADR-0021's fork-file policy, so one reorganization serves both.
- **Expected effect**: locality per handler; smaller review diffs (59-touch/month file becomes N low-collision files); fewer merge conflicts on both the upstream and parallel-develop axes; cheaper agent navigation of the test surface.
- **Seed coverage**: new-seed justification — `fabro-ab8e` names the same file but a different change (extract fork additions vs domain split); tracker searches found no seed owning the split.
