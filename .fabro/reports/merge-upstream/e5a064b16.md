  43a42ac, Pebble a39f43e -> 67c9f48 (one lithos crate held across all).
  Catalog schema: one `adapter` (default http) + `codecs = [...]`
  (default ["openai-chat"]) per provider; loader REJECTS the old
  `codec` key and the four protocol-named adapter ids. The four
  protocol features fold into `runtime`. OpenRouter and Fireworks now
  ship enabled; the built-in catalog passed 100 enabled rows

  provider's first codec. For us: our fork overlay (fabro-cd27) uses
  no codec/adapter keys and stays valid — proven by the new
  fork_catalog presence pin on the merged tree. New operator provider
  configs must use the codecs shape; the old shape fails loudly at
  load.
- **Worker control-stream give-up (#884, 1166caed0)**: a worker whose
  server is killed stops retrying after 60s (10s when orphaned to
  pid 1), goes fatal through control-loss (interrupts interviews,
  cancels the run), and the runner keeps driving the cancelled
  pipeline for a bounded grace so `conclude` can stop the sandbox
  before exit. Test-harness daemon reaper now also matches `.ft-`
  roots. For us: killed-server workers no longer leave never-stopped
  sandboxes — complements our sandbox GC (fabro-44d8) from the worker
  side; dev-host daemon litter shrinks.
